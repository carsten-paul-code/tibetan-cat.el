03Primer · so the rest makes sense

What is a CAT-Tool?

Computer-Assisted Translation. Not the same as Machine Translation — the human stays in the chair. The tool handles the bookkeeping of segments, glossaries, and previously-translated material so the translator can spend their attention on the language.

01 / SEGMENTATION
Chop the source into translatable units — sentence, clause, segment.
02 / TRANSLATION MEMORY
Remember every (source → target) pair. Suggest a match when similar text re-appears.
03 / TERMBASE
A project-specific glossary, hand-curated, consulted at every token.
;; existing CAT tools — Wordfast · OmegaT · Trados · MemoQ — are built for European-language commercial translation. Tibetan breaks all three pillars at once.

08Feature 03 · 2nd sem · Bialek

Particle recognition — the hard case.

The wallBialek's exercises were full of cases where a particle is glued onto its stem. One syllable on the page, two morphemes in the grammar. Get this wrong and every later layer — clause segmentation, argument structure, translation — collapses. Particle recognition is the preposition; everything else builds on it.
དེས
=
དེ + ས
ergative particle on a vowel-final demonstrative — not the past stem of a verb.
SINGLE-ས WHITELIST
དེ  ·  འདི  ·  ཁོ  ·  མོ  ·  ང  ·  སུ  ·  བུ  ·  མཐུ
Reference: Joanna Bialek, A Textbook in Classical Tibetan — Portfolio sections inlined into the Claude system prompt.
And then → particles were one half. The other half — the markers that bind clauses together — came in the third semester, with deeper texts and the Bialek Portfolio.
● tibetan-particles-bialek.el (Tibetan · Grammar)

09Feature 04 · 3rd sem · Bialek Portfolio

Converb recognition.

The wallThird semester. Reading deeper into the corpus — the Tigress jātaka, Tibetan Buddhist texts — I needed the markers that bind clauses together. Converbs aren't standalone words; they're suffixes that tell you how this clause connects to the next: causally, conditionally, simultaneously, sequentially. Without converb recognition, the segmenter has no clause boundaries to work with.
CONVERB SUFFIXES · BIALEK PORTFOLIO
ནས nas — sequential / ablative · "having…" ཏེ / སྟེ / དེ te / ste / de — coordinative · "and…" ཞིང / ཅིང / ཤིང zhing — simultaneous · "while…" པས / བས pas / bas — causal · "because…" ན na — conditional · "if / when…"
Each converb attaches a TYPE label that flows into clause analysis.
EXAMPLE
ཕྱིན་ནས ལྟས།
"having gone, (he) looked." — sequential converb nas binds the verb phyin to the following main verb ltas.
The same Bialek Portfolio sections that document each converb form get inlined into the Claude system prompt — so when the model proposes a translation, it has read the same definition.
analysis/tibetan-clause-segmenter.el · converb-suffixes table
And then → with particles AND converbs both legible, the segmenter has what it needs to walk the source.
● converbs.tib (Tibetan · Portfolio)

14Calibration · 4th sem · accountable AI

Context for AI translation.

The wallAn AI translation is only as accountable as its inputs. The system bundles a context block — Bialek Portfolio sections, multi-source dictionary entries, verb classification, Particle Map — into every AI request. Claude consumes this today (Anthropic prompt cache at ~10% input cost). The same context block is what an extended DharmaMitra would consume.
PER-SEGMENT SYSTEM PROMPT
▸ Bialek Portfolio §X — relevant sections only
▸ Multi-source dictionary entries for every token
▸ Verb classification (Hill 2010) for every verb
▸ Particle Map with case tags
▸ Sanskrit text + analysis (parallel mode only)
▸ User Working Translation drafts — preserved
▸ Target language directive (next slide)
The same scholarly references the human translator opens — bundled and sent every time.
PROMPT CACHING · CLAUDE TODAY · DM TOMORROW
(let ((gptel-cache '(system)))
  …)
The system prompt is cached at about 10% of input cost for the rest of the session. Without this, long sessions wouldn't be affordable.
Result: a translation suggestion (Claude today; an extended DM tomorrow) that names the particles it relied on, the dictionary sense it picked, the grammatical analysis it followed. Replaceable. Argued with. Not a black box. The context architecture is the durable contribution — it survives whichever AI consumes it.
And then → the next layer of calibration: which language the AI answers in.
